# LocaTester — Windows から iPhone の位置情報をテストできるツール（500円）

位置情報を使うアプリの開発・動作確認のためのツールです。
Windows パソコンに USB でつないだ iPhone の位置情報を、地図で指定した場所に変更できます。
Mac や Xcode がなくても使えます。

## できること

- 地図をクリックするだけで、iPhone の位置情報を変更
- 住所・地名検索、座標の直接入力
- ワンクリックで元の位置に戻す
- **設定アプリに「デベロッパモード」が表示されない iPhone でも、自動で表示・有効化**（パスコード未設定の場合は全自動）
- iOS の更新に合わせて、通信部分を起動時に自動更新

## 動作環境

- Windows 10 / 11
- iOS 17 以降の iPhone（iOS 16 以前も一部対応）
- USB ケーブル、インターネット接続（初回）
- Microsoft Store の「Apple Devices」アプリ（無料）
