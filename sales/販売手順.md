# 販売手順チェックリスト

## 0. 出品前に一度だけやること

- [ ] **製品名の商標チェック**: [J-PlatPat](https://www.j-platpat.inpit.go.jp/) で「LocaTester」「ロケテスタ」が登録されていないか確認する。
      使えない場合は `gps-simulator/main.py` の `PRODUCT_NAME` と `index.html` の `<title>` を変更する
- [ ] **販売サイトへの事前確認**: 下の「問い合わせ文」を note / BOOTH の事務局に送り、出品してよいか確認する
- [ ] **特定商取引法の表記**を `特定商取引法に基づく表記.md` から作り、販売ページに載せる
- [ ] **利用規約**（`利用規約.md`）を販売ページに載せる
- [ ] **自分の iPhone で製品版・動作チェック版の両方を試す**
- [ ] 動作確認できた pymobiledevice3 のバージョンを `gps-simulator/known_good.txt` に書く
      （`diagnose.bat` の出力の `Version:` 行で確認できる）
- [ ] リポジトリを非公開にするか確認する（公開のままだと誰でも無料で入手できる）

### 販売サイトへの問い合わせ文（例）

> 件名: 出品可否の確認（Windows 用ソフトウェア）
>
> いつもお世話になっております。以下の商品を出品したいと考えており、ガイドライン上問題がないかご確認いただけますでしょうか。
>
> - 内容: Windows パソコンから USB 接続した iPhone の位置情報をテスト用に変更するソフトウェア
> - 用途: 位置情報を使うアプリの開発・動作確認
> - 仕組み: Apple が開発者向けに提供している公式の機能（デベロッパモード・位置情報シミュレーション）を利用します。ゲーム等の第三者アプリの改造や、サーバーへのアクセスは行いません
> - 形式: zip ファイル（ソースコード同梱、GPL-3.0）
> - 価格: 2,980 円
>
> よろしくお願いいたします。

## 1. 配布ファイルを作る

```
python tools/build_release.py
```

`dist/` に次の2つができる。

| ファイル | 用途 |
|---|---|
| `LocaTester-<版>-check.zip` | 動作チェック版（無料で配布） |
| `LocaTester-<版>-full.zip` | 製品版（有料） |

## 2. 出品する

- note: 無料記事（`note記事_無料.md`）を公開 → 記事末尾から有料記事（または BOOTH）へ誘導
- 有料記事 / BOOTH の商品ページ: `商品ページ.md` を貼り付け、`full.zip` を添付
- 動作チェック版は無料記事・無料商品として `check.zip` を添付

**書かないこと**: ゲーム名（ポケモンGO 等）、「BANされない」「バレない」、勤怠ごまかし等の用途、Apple・任天堂等のロゴ

## 3. 年に一度の更新（iOS の大型アップデート後、秋ごろ）

1. 新しい iOS に自分の iPhone を更新し、動作チェック版・製品版を試す
2. 動かなければ修正する（多くは pymobiledevice3 の更新で直る）
3. `main.py` の `APP_VERSION` を `2027.xx` のように上げる
4. `known_good.txt` を動作確認したバージョンに更新
5. `python tools/build_release.py` で zip を作り直す
6. 「2027年度版」として新しく出品。前年度の購入者向けに割引価格（例: 980 円）を案内
7. 前年度版の商品ページに「iOS xx 以降は 2027年度版をご利用ください」と追記

## 4. ふだんの運用

- 問い合わせには原則対応しない（商品ページにも明記済み）
- ただし、多くの人に共通する不具合の報告が来たら、商品ページの FAQ に追記する
