# 販売手順チェックリスト

## 0. 出品前に一度だけやること

- [ ] **製品名の商標チェック**: [J-PlatPat](https://www.j-platpat.inpit.go.jp/) で「LocaTester」「ロケテスタ」が登録されていないか確認する。
      使えない場合は `gps-simulator/main.py` の `PRODUCT_NAME` と `index.html` の `<title>` を変更する
- [ ] **（任意）note への事前確認**: 必須ではない。理由と判断材料は `根拠一覧.md` の「note の規約」を参照。
      心配なら、下の「問い合わせ文」を note の事務局に送る
- [ ] **著作権者名**: `tools/build_release.py` の `COPYRIGHT_HOLDER` を自分の名前（またはペンネーム）に変える（GPL v3 第4条で、配布する各複製に著作権表示が必要）
- [ ] **特定商取引法の表記**を `特定商取引法に基づく表記.md` から作り、販売ページに載せる
- [ ] **利用規約**（`利用規約.md`）を販売ページに載せる
- [ ] **自分の iPhone で製品版・動作チェック版の両方を試す**
- [ ] 動作確認できた pymobiledevice3 のバージョンを `gps-simulator/known_good.txt` に書く
      （`diagnose.bat` の出力の `Version:` 行で確認できる）
- [ ] リポジトリを非公開にするか確認する（公開のままだと誰でも無料で入手できる）

> - 仕組み: Apple が開発者向けに提供している公式の機能（デベロッパモード・位置情報シミュレーション）を利用します。ゲーム等の第三者アプリの改造や、サーバーへのアクセスは行いません
> - 形式: zip ファイル（ソースコード同梱、GPL-3.0）
> - 価格: 500 円
>
> よろしくお願いいたします。

## 1. 配布ファイルを作る

```
python tools/build_release.py
```

`dist/` に次の2つができる。

| ファイル | 用途 |
|---|---|
| `LocaTester-<版>-check.zip` | 動作チェック版（無料で配布） |
| `LocaTester-<版>-full.zip` | 製品版（有料） |

## 2. 出品する

- 無料記事（`note記事_無料.md`）を公開し、`check.zip`（動作チェック版）を添付する
- 有料記事（500 円）を作り、無料部分に `商品ページ.md` の内容、有料部分に `full.zip` を添付する
  - 添付は 1 ファイル 50MB まで、1 日のアップロード回数に上限あり（無料会員は 10 回）。zip は数十 KB なので問題ない
  - 返品不可の文言は、価格のすぐ近くに置く
- 無料記事の末尾に有料記事へのリンクを入れる

**書かないこと**: ゲーム名（ポケモンGO 等）、「BANされない」「バレない」、勤怠ごまかし等の用途、Apple・任天堂等のロゴ

## 3. 動かなくなったとき（任意）

売り切り・アップデートの約束なしなので、直す義務はありません。動かないという報告が増えたら、次のどちらかを選ぶ。

**A. 販売をやめる**
- 有料記事を非公開にするか、冒頭に「iOS xx 以降では動作しません」と書いて販売を止める

**B. 直して出し直す（売れていて、手間をかける価値があるとき）**
1. 自分の iPhone で動作チェック版・製品版を試し、修正する（多くは pymobiledevice3 の更新で直る）
2. `main.py` の `APP_VERSION` を上げ、`known_good.txt` を動作確認したバージョンに更新
3. `python tools/build_release.py` で zip を作り直す
4. 有料記事の添付ファイルを差し替えて、**ウェブ版（note.com）で**再公開する（購入者に更新通知を送れる。アプリで更新すると通知は送られない）。
   note ヘルプには「購入者は内容の増減にかかわらず全て閲覧でき、添付ファイルのダウンロードも制限されない」とあるため、既存の購入者も新しいファイルを入手できると考えられる（差し替えについての直接の記載は未確認）
