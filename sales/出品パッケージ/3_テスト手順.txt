出品前のテスト手順
==================================================

自分のWindowsパソコンとiPhoneで、上から順番に試してください。
「こうなればOK」と違う結果になったら、そこで止めて、画面に出たメッセージを送ってください。

用意するもの：
・LocaTester-2026.11-check.zip（動作チェック版）
・LocaTester-2026.11-full.zip（製品版）
・iPhoneとUSBケーブル


--------------------------------------------------
テスト1　動作チェック版（無料で配るほう）
--------------------------------------------------

やること：
1. LocaTester-2026.11-check.zip を右クリックして「すべて展開」を選ぶ
   （これまで使っていたフォルダとは別の場所に展開してください）
2. iPhoneをUSBでつなぎ、ロックを解除しておく
3. 展開したフォルダの中の start.bat をダブルクリックし、「はい」を押す

確かめること：
[ ] ブラウザに地図の画面が出る
[ ] 画面の右上に「LocaTester v2026.11 動作チェック版」と出ている
[ ] 画面の上のほうが「デバイス接続中」（緑の丸）になる
[ ] 緑のボタンに「動作チェック（位置は変わりません）」と書いてある
[ ] 地図のどこかをクリックして緑のボタンを押すと、「動作チェックOK（iOS ○○）」と出る
    （初めてのときは、数十秒から数分かかります）
[ ] iPhoneの位置は変わっていない
[ ] フォルダの中に「hold_location.py」というファイルが入っていない

終わったら、黒いウィンドウを閉じてください。


--------------------------------------------------
テスト2　製品版（500円で売るほう）
--------------------------------------------------

やること：
1. LocaTester-2026.11-full.zip を、テスト1とは別の場所に展開する
2. start.bat をダブルクリックし、「はい」を押す

確かめること：
[ ] 画面の右上に「LocaTester v2026.11」と出ている（「動作チェック版」の文字が無い）
[ ] 緑のボタンに「この位置をセット」と書いてある
[ ] 地図をクリックしてボタンを押すと、「位置を設定しました」と出る
[ ] iPhoneのマップアプリで、選んだ場所になっている
[ ] そのまま5分以上待っても、位置が元に戻らない
[ ] 別の場所をクリックしてボタンを押すと、新しい場所に変わる
[ ] 「位置情報をリセット」を押すと、元の位置に戻る
[ ] もう一度位置をセットしてから黒いウィンドウを閉じると、元の位置に戻る


--------------------------------------------------
テスト3　予備のファイル（製品版のフォルダで試す）
--------------------------------------------------

[ ] diagnose.bat をダブルクリックすると、メモ帳で diagnose.txt が開く
[ ] diagnose.txt の中の「Version:」の行に番号（例：11.49.0）が書いてある
    → この番号を教えてください
[ ] rollback.bat をダブルクリックすると、最後に「[OK] Done.」と出る
[ ] start-noupdate.bat をダブルクリックすると、テスト2と同じように使える
[ ] フォルダの中の README.txt をダブルクリックすると、説明書が文字化けせずに読める


--------------------------------------------------
テスト4　noteで試す（公開はしない）
--------------------------------------------------

1. noteで新しい記事を作り、下書きのまま、LocaTester-2026.11-check.zip を添付してみる

[ ] zipファイルをエラーなく添付できる
[ ] 下書きのプレビューから、zipファイルをダウンロードして展開できる

2. noteの「アカウント設定」に、販売者情報（特定商取引法に基づく表記）を登録する画面があるか確かめる


==================================================
全部OKだったら
==================================================

1. テスト3で確かめた「Version:」の番号を教えてください
   （調子が悪くなったときに戻す先のバージョンとして登録します）

2. noteの「アカウント設定」で、販売者情報（特定商取引法に基づく表記）を登録してください

3. 著作権者の名前を「penmawashi8-ux」以外にしたい場合は教えてください
   （zipファイルを作り直します）

4. noteに出品する
   ・2_有料記事.txt を使って、500円の有料記事を作る（有料部分に full.zip を添付）
   ・1_無料記事.txt を使って、無料記事を作る（check.zip を添付し、有料記事のリンクを貼る）
   ・有料記事の「【ここに無料記事のリンクを貼る】」に、無料記事のリンクを貼る

5. GitHubのリポジトリを「Private（非公開）」にする（まだの場合）
