# 出品前のテスト手順

自分の Windows パソコンと iPhone で、上から順に試してください。
各項目の「期待する結果」と違ったら、そこで止めて、画面のメッセージを送ってください。

用意するもの: `LocaTester-2026.11-check.zip`、`LocaTester-2026.11-full.zip`、iPhone、USB ケーブル

---

## A. 動作チェック版（無料で配るもの）

1. `LocaTester-2026.11-check.zip` を右クリック →「すべて展開」（デスクトップなど、今までのフォルダとは別の場所に）
2. iPhone を USB でつなぎ、ロックを解除する
3. 展開したフォルダの `start.bat` をダブルクリック →「はい」

| 確認すること | 期待する結果 | 結果 |
|---|---|---|
| ブラウザが開く | 地図の画面が出る | |
| 画面右上の表示 | `LocaTester v2026.11 動作チェック版` | |
| 画面上部の接続状態 | 🟢 デバイス接続中 | |
| 緑のボタンの文字 | `✅ 動作チェック（位置は変わりません）` | |
| 地図をクリック → 緑のボタンを押す | 「✅ 動作チェックOK（iOS xx.x）」と出る（初回は数十秒〜数分） | |
| iPhone の位置 | **変わらない** | |
| フォルダの中 | `hold_location.py` が**入っていない** | |

4. 黒いウィンドウを閉じる

## B. 製品版（500 円で売るもの）

1. `LocaTester-2026.11-full.zip` を、A とは**別の場所**に展開
2. `start.bat` をダブルクリック →「はい」

| 確認すること | 期待する結果 | 結果 |
|---|---|---|
| 画面右上の表示 | `LocaTester v2026.11`（「動作チェック版」の文字が無い） | |
| 緑のボタンの文字 | `📍 この位置をセット` | |
| 地図をクリック → ボタンを押す | 「位置を設定しました」と出る | |
| iPhone のマップアプリ | 指定した場所になる | |
| **そのまま 5 分以上待つ** | 位置が戻らない | |
| 別の場所をクリック → ボタン | 新しい場所に変わる | |
| 「位置情報をリセット」 | 元の位置に戻る | |
| もう一度セット → 黒いウィンドウを閉じる | 元の位置に戻る | |

## C. 予備の起動方法

製品版のフォルダで試す。

| 確認すること | 期待する結果 | 結果 |
|---|---|---|
| `diagnose.bat` をダブルクリック | メモ帳で `diagnose.txt` が開く | |
| `diagnose.txt` の `Version:` の行 | バージョン番号（例: 11.49.0）が書いてある → **この番号を教えてください** | |
| `rollback.bat` をダブルクリック | `[OK] Done.` と出る | |
| `start-noupdate.bat` をダブルクリック | B と同じように使える | |

## D. note でのテスト（公開しない）

1. note で新しい記事を作り、**下書きのまま**、`LocaTester-2026.11-check.zip` を添付してみる

| 確認すること | 期待する結果 | 結果 |
|---|---|---|
| zip を添付できるか | エラーなく添付できる | |
| 下書きのプレビューでダウンロード | zip がダウンロードでき、展開できる | |

2. note の「アカウント設定」に、販売者情報（特定商取引法に基づく表記）を登録する画面があるか確認する

---

## テストが全部 OK だったら

1. C で確認したバージョン番号を教えてください（`known_good.txt` に書きます）
2. `2_有料記事.txt` の利用規約にある次の 2 か所を埋める
   - 「（販売者名）」→ 自分の名前
   - 「（販売者の住所地を管轄する地方裁判所）」→ 例: 東京地方裁判所
3. 著作権者名を `penmawashi8-ux` 以外にしたい場合は教えてください（zip を作り直します）
4. note に出品する
   1. `2_有料記事.txt` で有料記事を作る（500 円）。有料部分に `full.zip` を添付
   2. `1_無料記事.txt` で無料記事を作る。`check.zip` を添付し、有料記事のリンクを貼る
   3. 有料記事の【ここに無料記事のリンクを貼る】に、無料記事のリンクを貼る
5. GitHub のリポジトリを Private にする（まだなら）
