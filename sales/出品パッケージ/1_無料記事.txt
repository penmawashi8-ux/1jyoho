Windowsのパソコンから、iPhoneの位置情報を変更してテストする方法をまとめました。Macがなくてもできます。iOS 26.6.2のiPhoneで実際に動くことを確かめています。

設定アプリに「デベロッパモード」が表示されないときの出し方や、「Failed to start service」というエラー、位置情報が数十秒で元に戻ってしまう問題の直し方も書いています。

こんな方に向けた記事です。

・位置情報を使うアプリを作っていて、別の場所での動作をWindowsで確かめたい
・iPhoneの設定に「デベロッパモード」が表示されなくて困っている
・pymobiledevice3で位置情報を変えようとしたらエラーが出た、またはすぐ元に戻ってしまう


■ WindowsでiPhoneの位置情報をテストするのが難しい理由

Macがあれば、Xcodeという開発ツールで簡単に位置情報を変えられます。ところがXcodeはMac専用で、Windowsでは使えません。

しかもiOS 17からは、パソコンとiPhoneのつなぎ方が大きく変わりました。古い情報の手順では動かないことが多いです。

この記事では、無料で公開されている「pymobiledevice3（パイモバイルデバイス・スリー）」というツールを使います。


■ 用意するもの

・Windows 10 または 11 のパソコン
・iOS 17以降のiPhone（この記事ではiOS 26.6.2で確認）と、USBケーブル
・Python（パイソン）3.10以上
・Microsoft Storeの「Apple Devices」アプリ（無料。iPhoneをパソコンにつなぐために必要です）

Pythonを入れたら、コマンドプロンプトで次のように入力して、pymobiledevice3を入れます。

pip install pymobiledevice3


■ iPhoneの設定に「デベロッパモード」が表示されないときの対処

iOS 16からは、位置情報を変えるのに「デベロッパモード」という設定が必要になりました。

ところが、開発ツールにつないだことがないiPhoneだと、この項目は設定アプリに表示されません。

pymobiledevice3には、隠れている項目を表示させるコマンドがあります。iPhoneをUSBでつないで、次のように入力します。

pymobiledevice3 amfi reveal-developer-mode

すると、「設定」→「プライバシーとセキュリティ」の一番下に「デベロッパモード」が表示されます。

これをオンにすると、再起動を求められます。再起動したあと、ロックを解除したときに「デベロッパモードをオンにしますか？」と聞かれるので、「オンにする」をタップしてください。ここを飛ばすとオンになりません。

ちなみに、iPhoneにパスコードを設定していない場合は、次のコマンドで設定アプリを触らずにオンにできます。

pymobiledevice3 amfi enable-developer-mode

今オンになっているかどうかは、次のコマンドで確認できます。

pymobiledevice3 amfi developer-mode-status


■「Failed to start service」と表示されるときの対処

デベロッパモードをオンにしても、いきなり位置情報を変えようとすると、「Failed to start service」というエラーが表示されます。

iOS 17以降では、先に「開発用のディスクイメージ（Developer Disk Image）」をiPhoneに読み込ませる必要があります。Xcodeなら裏で自動的にやってくれる作業です。次のコマンドでできます。

pymobiledevice3 mounter auto-mount

初回はイメージのダウンロードがあるので、少し時間がかかります。

なお、デベロッパモードがオフのままこのコマンドを実行すると、「Developer Mode is disabled」と表示されます。その場合は、上の手順でデベロッパモードをオンにしてください。


■ iPhoneの位置情報を変更するコマンド

準備ができたら、次のように緯度と経度を指定します（例は東京駅です）。

pymobiledevice3 developer dvt simulate-location set -- 35.6812 139.7671

iOS 17以降は、パソコンとiPhoneの間に「トンネル」と呼ばれる専用の通り道が必要です。最近のpymobiledevice3は、これを管理者権限なしで自動的に作ってくれます。

元の位置情報に戻したいときは、Enterキーを押してコマンドを終わらせます。


■ 位置情報が数十秒で元に戻ってしまうときの対処

このコマンドは、動いている間だけ位置情報を保つ仕組みです。

ところが、管理者権限なしのトンネルを使っていると、待っている間に通信まで止まってしまいます。その結果、数十秒でiPhoneのほうから接続を切られて、位置情報が元に戻ってしまいました。

これを避けるには、pymobiledevice3をPythonのプログラムから直接使って、待っている間も通信を止めないようにする必要があります。定期的に位置を送り直して、切れたらつなぎ直す仕組みも入れておくと安定します。


■ まとめ：WindowsでiPhoneの位置情報を変更する手順

・デベロッパモードの項目を表示する　→　amfi reveal-developer-mode
・デベロッパモードをオンにする（パスコードなしの場合）　→　amfi enable-developer-mode
・開発用のディスクイメージを読み込ませる　→　mounter auto-mount
・位置情報を変更する　→　developer dvt simulate-location set -- 緯度 経度


■ コマンドを使わずに、地図をクリックするだけで位置情報を変更したい方へ

ここまでの作業をまとめて、地図をクリックするだけでiPhoneの位置情報を変更できるWindows用のツール「LocaTester（ロケテスタ）」を作りました。

【ここに画像「使い方3ステップ.png」を入れる】

・start.bat をダブルクリックするだけで起動します
・地図をクリックしたり、住所で検索したりして場所を選べます
・デベロッパモードが表示されないiPhoneでも、自動で表示・オンにします
・「Failed to start service」の原因になる準備も、自動で行います
・位置情報が数十秒で戻ってしまう問題にも対策してあります

まずは無料の「動作チェック版」で、お使いのパソコンとiPhoneで動くかどうかを確かめてみてください。


▼ 動作チェック版（無料）

【ここに LocaTester-2026.11-check.zip を添付】

使い方：
1. ダウンロードしたzipファイルを右クリックして、「すべて展開」を選びます
2. iPhoneをUSBでつなぎ、ロックを解除しておきます
3. 展開したフォルダの中の「start.bat」をダブルクリックします
4. ブラウザに地図が出たら、地図のどこかをクリックして、緑の「動作チェック」ボタンを押します

「動作チェックOK」と表示されれば、製品版が使える環境です。
（動作チェック版では、実際の位置情報は変わりません）
