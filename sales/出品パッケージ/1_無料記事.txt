【タイトル】
Windows で iOS 17 以降の iPhone の位置情報をテストする方法（デベロッパモードが表示されない場合も）

【本文】（ここから下を貼り付け。見出し「##」やコードブロック「```」は、note のエディタで見出し・コードの書式に設定し直してください）

位置情報を使うアプリを作っていると、「別の場所にいるときの動作」を確認したくなります。
Mac なら Xcode で簡単にできますが、**Windows だと情報が少なく、iOS 17 以降は手順も大きく変わりました**。

この記事では、オープンソースのライブラリ **pymobiledevice3** を使って、Windows から iPhone の位置情報を変更する手順と、実際にハマったポイントをまとめます。

---

## 必要なもの

- Windows 10 / 11
- iOS 17 以降の iPhone と USB ケーブル
- Python 3.10 以上
- Microsoft Store の「Apple Devices」アプリ（iPhone 用のドライバが入ります）

```
pip install pymobiledevice3
```

---

## ハマりどころ1: 設定に「デベロッパモード」が無い

iOS 16 以降、位置情報のシミュレーションには **デベロッパモード** が必須です。
ところが、Xcode に接続したことがない iPhone では、**設定アプリにこの項目が表示されません**。

pymobiledevice3 には、項目を表示させるコマンドがあります。

```
pymobiledevice3 amfi reveal-developer-mode
```

これで「設定」→「プライバシーとセキュリティ」の一番下に「デベロッパモード」が出てきます。
ON にすると再起動を求められるので再起動し、**ロック解除時の確認で「オンにする」をタップ**します（これを忘れると ON になりません）。

パスコードを設定していない iPhone なら、次のコマンドで設定を触らずに有効化できます。

```
pymobiledevice3 amfi enable-developer-mode
```

状態の確認は次のとおりです。

```
pymobiledevice3 amfi developer-mode-status
```

---

## ハマりどころ2: 「Failed to start service」

デベロッパモードを ON にしても、いきなり位置を変えようとするとこのエラーになります。
iOS 17 以降は、**開発用のディスクイメージ（Personalized Developer Disk Image）を iPhone にマウント**する必要があります。Xcode が裏でやっている処理です。

```
pymobiledevice3 mounter auto-mount
```

初回はイメージのダウンロードがあるので少し時間がかかります。

---

## 位置を変更する

```
pymobiledevice3 developer dvt simulate-location set -- 35.6812 139.7671
```

iOS 17 以降は PC と iPhone の間に「トンネル」と呼ばれる通信路が必要ですが、最近の pymobiledevice3 は管理者権限なしで自動的に作ってくれます。

元に戻すときは、コマンドを終了（Enter）します。

---

## ハマりどころ3: 数十秒で位置が元に戻る

このコマンドは、**実行している間だけ**位置を保持します。
さらに、管理者権限なしのトンネル（userspace トンネル）を使っている場合、待機中に通信が止まってしまい、**数十秒で iPhone 側から接続を切られて位置が戻る**ことがありました。

対策としては、pymobiledevice3 を Python から直接使い、待機中もイベントループを止めないようにする必要があります（定期的に位置を再送し、切れたら再接続する処理も入れると安定します）。

---

## まとめ

- デベロッパモードの項目を表示: amfi reveal-developer-mode
- デベロッパモードを有効化（パスコードなし）: amfi enable-developer-mode
- 開発用イメージをマウント: mounter auto-mount
- 位置を変更: developer dvt simulate-location set -- 緯度 経度

---|---|
| デベロッパモードの項目を表示 | `amfi reveal-developer-mode` |
| デベロッパモードを有効化（パスコードなし） | `amfi enable-developer-mode` |
| 開発用イメージをマウント | `mounter auto-mount` |
| 位置を変更 | `developer dvt simulate-location set -- 緯度 経度` |

## コマンドが面倒な方へ

ここまでの手順（デベロッパモードの自動表示・有効化、開発用イメージのマウント、数十秒で戻る問題の対策）を全部まとめて、**地図をクリックするだけで使えるツール「LocaTester」** にしました。

- `start.bat` をダブルクリックするだけで起動
- 地図・住所検索で位置を指定
- デベロッパモードが表示されない iPhone でも自動で対処
