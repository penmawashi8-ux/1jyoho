タイトル：
Windowsで、新しいiOSのiPhoneの位置情報をテストする方法（設定にデベロッパモードが出ない場合も）

--------------------------------------------------
ここから下を本文に貼り付けてください
--------------------------------------------------

位置情報を使うアプリを作っていると、「別の場所にいるときにどう動くか」を確かめたくなることがあります。

Macがあれば、Xcodeという開発ツールで簡単にできます。ところがWindowsだと情報が少なく、しかもiOS 17からは手順が大きく変わりました。

この記事では、無料で公開されている「pymobiledevice3（パイモバイルデバイス・スリー）」というツールを使って、WindowsからiPhoneの位置情報を変える方法をまとめます。実際にやってみて、つまずいたところも一緒に書いておきます。


■ 用意するもの

・Windows 10 または 11 のパソコン
・iOS 17以降のiPhoneと、USBケーブル
・Python（パイソン）3.10以上
・Microsoft Storeの「Apple Devices」アプリ（無料。iPhoneをパソコンにつなぐために必要です）

Pythonを入れたら、コマンドプロンプトで次のように入力して、pymobiledevice3を入れます。

pip install pymobiledevice3


■ つまずいたところ その1：設定に「デベロッパモード」が無い

iOS 16からは、位置情報を変えるのに「デベロッパモード」という設定が必要になりました。

ところが、開発ツールにつないだことがないiPhoneだと、この項目は設定アプリに出てきません。

pymobiledevice3には、隠れている項目を表示させるコマンドがあります。iPhoneをUSBでつないで、次のように入力します。

pymobiledevice3 amfi reveal-developer-mode

すると、「設定」→「プライバシーとセキュリティ」の一番下に「デベロッパモード」が出てきます。

これをオンにすると、再起動を求められます。再起動したあと、ロックを解除したときに「デベロッパモードをオンにしますか？」と聞かれるので、「オンにする」をタップしてください。ここを飛ばすとオンになりません。

ちなみに、iPhoneにパスコードを設定していない場合は、次のコマンドで設定アプリを触らずにオンにできます。

pymobiledevice3 amfi enable-developer-mode

今オンになっているかどうかは、次のコマンドで確認できます。

pymobiledevice3 amfi developer-mode-status


■ つまずいたところ その2：「Failed to start service」と出る

デベロッパモードをオンにしても、いきなり位置を変えようとすると、このエラーが出ます。

iOS 17以降では、先に「開発用のディスクイメージ」をiPhoneに読み込ませる必要があります。Xcodeなら裏で自動的にやってくれる作業です。次のコマンドでできます。

pymobiledevice3 mounter auto-mount

初回はイメージのダウンロードがあるので、少し時間がかかります。


■ 位置を変える

準備ができたら、次のように緯度と経度を指定します（例は東京駅です）。

pymobiledevice3 developer dvt simulate-location set -- 35.6812 139.7671

iOS 17以降は、パソコンとiPhoneの間に「トンネル」と呼ばれる専用の通り道が必要です。最近のpymobiledevice3は、これを管理者権限なしで自動的に作ってくれます。

元の位置に戻したいときは、Enterキーを押してコマンドを終わらせます。


■ つまずいたところ その3：数十秒で位置が元に戻ってしまう

このコマンドは、動いている間だけ位置を保つ仕組みです。

ところが、管理者権限なしのトンネルを使っていると、待っている間に通信まで止まってしまいます。その結果、数十秒でiPhoneのほうから接続を切られて、位置が元に戻ってしまいました。

これを避けるには、pymobiledevice3をPythonのプログラムから直接使って、待っている間も通信を止めないようにする必要があります。定期的に位置を送り直して、切れたらつなぎ直す仕組みも入れておくと安定します。


■ まとめ

・デベロッパモードの項目を出す　→　amfi reveal-developer-mode
・デベロッパモードをオンにする（パスコードなしの場合）　→　amfi enable-developer-mode
・開発用イメージを読み込ませる　→　mounter auto-mount
・位置を変える　→　developer dvt simulate-location set -- 緯度 経度


■ コマンドが面倒な方へ

ここまでの作業をまとめて、地図をクリックするだけで使えるツール「LocaTester（ロケテスタ）」を作りました。

・start.bat をダブルクリックするだけで起動します
・地図をクリックしたり、住所で検索したりして場所を選べます
・デベロッパモードが出てこないiPhoneでも、自動で表示・オンにします
・数十秒で戻ってしまう問題にも対策してあります

まずは無料の「動作チェック版」で、お使いのパソコンとiPhoneで動くかどうかを確かめてみてください。


▼ 動作チェック版（無料）

【ここに LocaTester-2026.11-check.zip を添付】

使い方：
1. ダウンロードしたzipファイルを右クリックして、「すべて展開」を選びます
2. iPhoneをUSBでつなぎ、ロックを解除しておきます
3. 展開したフォルダの中の「start.bat」をダブルクリックします
4. ブラウザに地図が出たら、地図のどこかをクリックして、緑の「動作チェック」ボタンを押します

「動作チェックOK」と表示されれば、製品版が使える環境です。
（動作チェック版では、実際の位置は変わりません）
