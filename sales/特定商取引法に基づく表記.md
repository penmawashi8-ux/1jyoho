# 特定商取引法に基づく表記（テンプレート）

（ ）内を埋めて販売ページに掲載してください。根拠は `根拠一覧.md` を参照。

- **氏名は戸籍上の氏名**で書く（屋号だけでは足りない。消費者庁「通信販売広告Q＆A」）
- 氏名・住所・電話番号は、「請求があれば遅滞なく提供する」旨を表示し、**実際に請求があったら遅滞なく（目安は1週間程度）提供できる体制**があれば省略できる（同Q＆A、逐条解説）
- **返品不可の表示は、価格の近くに、目立つように**載せる（消費者庁「通信販売における返品特約の表示についてのガイドライン」）。表示しないと、引渡しから8日間は返品が認められる
- note には販売者情報（特定商取引法に基づく表記）を登録する設定がある。手順は note ヘルプ「特商法の表示について」を確認する（このセッションでは note のページを直接開けず、未確認）

| 項目 | 内容 |
|---|---|
| 販売事業者名 | （戸籍上の氏名。屋号を併記するのは可） |
| 運営責任者 | （氏名） |
| 所在地 | 請求があった場合には遅滞なく開示いたします |
| 電話番号 | 請求があった場合には遅滞なく開示いたします |
| メールアドレス | （連絡先メールアドレス） |
| 販売価格 | 各商品ページに記載（税込） |
| 商品代金以外の必要料金 | なし（インターネット接続料金・通信料はお客様のご負担となります） |
| 支払方法 | 各販売サイトが提供する決済方法 |
| 支払時期 | 各販売サイトの定めによります |
| 商品の引渡時期 | 決済完了後、直ちにダウンロード可能 |
| 返品・キャンセル | デジタルコンテンツの性質上、購入後の返品・キャンセルはお受けできません。購入前に無料の動作チェック版で動作をご確認ください |
| 動作環境 | Windows 10 / 11、iOS 17 以降の iPhone（詳細は商品ページを参照） |
