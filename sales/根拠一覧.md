# 根拠一覧

販売用の書類に書いた内容の根拠と、確認の度合いをまとめたもの。

**確認の度合い**
- ✅ 一次情報で確認: 公式ページ・条文・配布物そのものを確認した
- 🔎 検索結果で確認: 公式サイトの内容を検索結果の抜粋で確認した（ページ全体は読めていない）
- ⚠️ 二次情報のみ: 個人ブログ・解説記事しか見つからなかった
- ❓ 未確認: 根拠が見つからなかった

> このクラウド環境では note.com / help-note.com / 消費者庁 / e-Gov 法令検索のページを直接開けなかった（ネットワーク設定で許可されていない）。
> そのため、それらは検索結果の抜粋による確認（🔎）になっている。許可されれば ✅ に上げられる。

## note の機能・手数料

| 内容 | 度合い | 根拠 |
|---|---|---|
| 有料記事にファイルを添付して販売できる | 🔎 | note ヘルプ「動画やファイルを販売する」、note 公式「ファイルをアップロードできるようになりました」 |
| 添付は 1 ファイル 50MB まで、1 日のアップロード回数に上限（無料会員 10 回） | 🔎 | note ヘルプ「ファイルアップロード機能について」 |
| zip を添付できる | ⚠️ | 公式ヘルプに「アップロードできない場合は Zip 形式に圧縮」とあるという引用（個人ブログ経由）。対応形式の一覧は公式で未確認 |
| 購入者は、記事の内容の増減にかかわらず全て閲覧でき、添付ファイルのダウンロードも制限されない | 🔎 | note ヘルプ「有料記事の値上げ前に購入した人が値上げ後の記事を読むためには…」 |
| 添付ファイルを差し替えたとき、既存の購入者が新しいファイルを入手できる | ❓ | 直接の記載なし（上の記述から、できると考えられる） |
| 有料記事をウェブ版で更新・再公開すると購入者に通知でき、アプリで更新すると通知されない | 🔎 | note ヘルプ「アプリで有料記事を更新した際に、更新通知が購入者へ送信されない」、note 公式「有料ノートを公開後に更新したときは、通知でお知らせできます。」 |
| 手数料: 決済手数料（クレジットカード 5% など）＋プラットフォーム利用料 10%、振込手数料 270 円 | ⚠️ | 個人ブログ複数（公式の料率ページは未確認）。**出品前に note 公式で確認すること** |

## 特定商取引法

| 内容 | 度合い | 根拠 |
|---|---|---|
| 通信販売の広告には販売業者の氏名・住所・電話番号等の表示が必要 | 🔎 | 特定商取引法第11条、消費者庁「通信販売広告について」 |
| 「請求があれば遅滞なく提供する」旨を表示し、実際に提供できる体制があれば、氏名・住所・電話番号を省略できる | 🔎 | 消費者庁「通信販売広告Q＆A」 |
| 「遅滞なく」の目安は 1 週間程度 | 🔎 | 消費者庁 特定商取引法 逐条解説（第11条） |
| 個人の氏名は戸籍上の氏名（屋号だけでは足りない） | 🔎 | 消費者庁「通信販売広告Q＆A」 |
| 返品特約（返品不可を含む）は広告に明示が必要。表示がなければ引渡しから 8 日間は返品可能 | 🔎 | 消費者庁「通信販売広告について」「広告に返品特約がない場合、8日間以内であれば返品も可能に」 |
| 返品特約は、価格など消費者が必ず確認する事項の近くに、埋没しない形で表示する | 🔎 | 消費者庁「通信販売における返品特約の表示についてのガイドライン」 |
| デジタルコンテンツ特有の返品ルール | ❓ | 見つからなかった |
| 単発・少数の販売なら「販売業者」に当たらず表示不要の場合がある | ⚠️ | 個人ブログ。**表示しておくのが安全** |

## 消費者契約法（利用規約の免責条項）

| 内容 | 度合い | 根拠 |
|---|---|---|
| 事業者の損害賠償責任を**全部**免除する条項は無効 | 🔎 | 消費者契約法第8条第1項第1号・第3号、消費者庁「消費者契約法 逐条解説（第8条）」 |
| 故意・重大な過失の場合に責任を一部免除する条項は無効 | 🔎 | 同第8条第1項第2号・第4号 |
| 軽過失の場合に限って一部免除（上限設定）する条項は、軽過失の場合に限ることを明記すれば有効 | 🔎 | 同第8条第3項（2022年改正）、消費者庁 逐条解説。「法律上許される限り」等の書き方では足りない |
| 軽過失の責任を全部免除する条項は無効とするのが消費者庁の解説の立場（学説は分かれる） | 🔎 | 消費者庁 逐条解説、消費者契約に関する検討会 議事録 |

→ 利用規約 第7条を「軽過失の場合に限り、代金額を上限とする」形に修正した。
