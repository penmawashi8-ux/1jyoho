# iPhone GPS シミュレーター（Windows対応）

ブラウザ上の地図UIからiPhoneの位置情報を自由にシミュレートできるローカルWebアプリです。

---

## iPhone側の準備

1. **デベロッパーモードを有効化**
   - 「設定」→「プライバシーとセキュリティ」→「デベロッパーモード」→ ON
   - 再起動を求められるので再起動し、確認ダイアログで「オンにする」をタップ

2. **USBでWindowsに接続**
   - iPhoneとWindowsをUSBケーブルで接続
   - iPhoneに「このコンピュータを信頼しますか？」と表示されたら「信頼」をタップ
   - パスコードを入力して確認

---

## Windows側の準備

### 1. Apple Devices アプリのインストール（USBドライバ）

- **Microsoft Store** を開き「Apple Devices」で検索してインストール（無料）
- または Apple 公式サイトから iTunes をインストールしてもドライバが導入されます
- インストール後、アプリを起動してiPhoneが認識されることを確認してください

### 2. セットアップ（初回のみ）

`setup.bat` をダブルクリックして実行します。
- Pythonのバージョン確認
- 仮想環境（venv）の作成
- 必要パッケージのインストール

> **注意**: Python 3.10以上が必要です。インストールされていない場合は https://www.python.org/downloads/ からダウンロードしてください。

### 3. tunneld の起動（毎回必要・管理者権限が必要）

**コマンドプロンプトを管理者として実行**し、以下を入力します。

```
pymobiledevice3 remote tunneld
```

このウィンドウは **サーバー起動中ずっと開いたまま** にしておく必要があります。閉じると接続が切れます。

> **なぜ tunneld が必要？**
> iOS 17以降では、デバイスとの通信にRemote XPC（TCP経由）が使われます。`tunneld` はそのための中継トンネルをローカルで確立するコマンドです。管理者権限が必要なのは、仮想ネットワークインターフェースを作成するためです。

### 4. アプリの起動

別のコマンドプロンプト（管理者権限不要）で `start.bat` をダブルクリックするか実行します。

```
start.bat
```

サーバーが起動し、3秒後にブラウザで `http://localhost:8000` が自動で開きます。

## 使い方

| 操作 | 方法 |
|------|------|
| 位置を選ぶ | 地図をクリック / 住所検索 / プリセットボタン / 座標直接入力 |
| iPhoneに反映 | 「この位置をセット」ボタンをクリック |
| 元に戻す | 「位置情報をリセット」ボタンをクリック |
| 接続確認 | 画面上部のステータスバー（🟢接続中 / 🔴未接続） |

## トラブルシューティング

### デバイスが認識されない（🔴のまま）

1. **Apple Devices アプリを開いて確認**
   - アプリ起動後、左側にiPhoneが表示されていることを確認
   - 表示されない場合はケーブルを抜き差しし、iPhoneで「信頼」をタップ

2. **tunneldが起動しているか確認**
   - 管理者権限のコマンドプロンプトで `pymobiledevice3 remote tunneld` が動いているか確認
   - 終了していたら再起動する

3. **iPhoneのデベロッパーモードを再確認**
   - 「設定」→「プライバシーとセキュリティ」→「デベロッパーモード」がONになっているか確認

### ポート8000が使用中の場合

`start.bat` をテキストエディタで開き、以下の行のポート番号を変更します。

```
uvicorn main:app --host 0.0.0.0 --port 8000
```

例えば `--port 8080` に変更し、ブラウザで `http://localhost:8080` を開いてください。

### 「位置設定エラー」が出る

- tunneldが起動中か確認してください
- iPhoneのロックを解除した状態で試してください
- iPhoneを再接続してみてください
