# LocaTester 取扱説明書

Windows パソコンから、USB でつないだ iPhone の位置情報を地図で指定してテストできるツールです。
位置情報を使うアプリの開発・動作確認のためのツールです。

---

## 動作環境

| 項目 | 条件 |
|------|------|
| パソコン | Windows 10 / 11 |
| iPhone | iOS 17 以降（iOS 16 以前も一部対応） |
| 接続 | USB ケーブル（データ通信対応のもの） |
| インターネット | 初回起動時と、初めて位置をセットするときに必要 |
| その他 | Microsoft Store の「Apple Devices」アプリ（無料）、Python 3.10 以上（無ければ自動でインストールを試みます） |

> **購入前に、無料の「動作チェック版」で動作を確認してください。**
> 動作チェック版は、位置を変更する直前までの全ての手順（接続・デベロッパーモード・開発用イメージ）を確認できます。
> 動作チェックが OK にならない環境では製品版も動作しません。

---

## はじめての使い方

### 1. Apple Devices アプリを入れる
Microsoft Store で「Apple Devices」を検索してインストールし、一度起動します。
（iPhone とパソコンをつなぐためのドライバが入ります。iTunes でも可）

### 2. iPhone をつなぐ
1. USB ケーブルで iPhone とパソコンをつなぐ
2. iPhone のロックを解除する
3. 「このコンピュータを信頼しますか？」と出たら「信頼」をタップし、パスコードを入力

### 3. 起動する
フォルダ内の **`start.bat` をダブルクリック**します。

- 「このアプリがデバイスに変更を加えることを許可しますか？」→ **「はい」**
- 初回のみセットアップ（数分）が自動で行われます
- ブラウザで操作画面が開きます

### 4. 位置をセットする
地図をクリック（または住所検索）して、**「📍 この位置をセット」** を押します。

- 初回は開発用イメージの準備があるため、**数十秒〜数分**かかります
- **デベロッパーモードが OFF の場合は自動で対処します**（下記参照）

### デベロッパーモードについて
iOS 16 以降では、位置情報のテストに iPhone の「デベロッパモード」が必要です（Apple の仕様）。
設定アプリに項目が表示されていない iPhone でも、このツールが自動で表示させます。

- **パスコード未設定の iPhone**: 自動で ON になります（iPhone が再起動します）
- **パスコード設定済みの iPhone**: 「設定」→「プライバシーとセキュリティ」→一番下の「デベロッパモード」を ON → 再起動 → ロック解除時の確認で **「オンにする」** をタップ

一度 ON にすれば、次回からは不要です。

## 操作方法

| 操作 | 方法 |
|------|------|
| 位置を選ぶ | 地図をクリック / 住所検索 / プリセット / 座標入力 |
| iPhone に反映 | 「この位置をセット」 |
| 元に戻す | 「位置情報をリセット」 |
| 接続状態 | 画面上部（🟢接続中 / 🔴未接続） |

> iOS 17 以降は、**黒いウィンドウを開いている間だけ**位置が保たれます。閉じると元の位置に戻ります。

## 困ったとき（よくある質問）

画面に表示されるメッセージを確認し、下の表で対処してください。

| 症状・メッセージ | 対処 |
|---|---|
| 🔴未接続のまま | ケーブルを挿し直す → iPhone のロック解除 → 「信頼」をタップ。Apple Devices アプリで iPhone が見えるか確認 |
| 「Apple Mobile Device Service に接続できません」 | Apple Devices アプリ（または iTunes）をインストールして一度起動し、パソコンを再起動 |
| 「デベロッパーモードが OFF」 | 上の「デベロッパーモードについて」の手順で ON にする |
| 「Python not found」/ 起動しない | 自動インストール後に `start.bat` をもう一度起動。失敗する場合は https://www.python.org/downloads/ から Python をインストール（「Add python.exe to PATH」にチェック） |
| 位置をセットすると「DDIマウント」のエラー | インターネットに接続されているか確認。iPhone のロックを解除して再実行 |
| 昨日まで動いていたのに急に動かない | 自動更新が原因の可能性があります。`rollback.bat` を実行し、以後は `start-noupdate.bat` で起動 |
| iOS をアップデートしたら動かない | 新しい iOS への対応版が出るまでお待ちください（下記「アップデート」参照） |
| ポート 8000 が使用中 | `start.bat` をメモ帳で開き、`--port 8000` を `--port 8080` などに変更 |

それでも解決しない場合は、`diagnose.bat` を実行すると `diagnose.txt` に診断情報が出力されます。
内容（特に ERROR の行）を確認すると原因の手がかりになります。

## アップデートについて

- `start.bat` は起動時に、iPhone との通信部分（pymobiledevice3）を自動で最新に更新します。iOS の小さなアップデートへの対応は、多くの場合これで行われます。
- iOS の大型アップデート（毎年秋）で動作しなくなった場合は、対応版を「年度版」として公開します。購入した年度版は、その年度中の更新版を購入ページから再ダウンロードできます。
- 動作の継続を保証するものではありません。

## ファイル構成

```
LocaTester/
├── start.bat           # 起動（自動更新あり）
├── start-noupdate.bat  # 起動（自動更新なし）
├── rollback.bat        # 自動更新で動かなくなったときに元に戻す
├── diagnose.bat        # 診断情報を diagnose.txt に出力
├── setup.bat           # セットアップ（start.bat から自動実行）
├── main.py             # 本体（サーバー）
├── index.html          # 操作画面
├── hold_location.py    # 位置を保持する補助プログラム（製品版のみ）
├── check_device.py     # 動作チェック用プログラム
├── requirements.txt    # 必要なパッケージ
└── known_good.txt      # rollback.bat で戻すバージョン
```
